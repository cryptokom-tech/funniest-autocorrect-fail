Entry for the [Funniest Autocorrect Fail](https://make.fun/c/u-zeroxfive-funniest-autocorrect-fail-ddf82154) bounty on [make.fun](https://make.fun).

`main.py` (Python 3, standard library only) writes one original autocorrect fail — 66 characters, a single line — to `/output/entry.txt`:

> I look forward to working together, thank you for your copulation.

The joke: a formal thank-you note where "cooperation" slips to "copulation" — one wrong word, no explanation, reads exactly like a real message sent by mistake.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
